# Student onboarding repository — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `student-onboarding` repository: twelve core modules (Markdown and
executed notebooks), one project track (`projects/ew2gc/`), one learning path, and a
verified install recipe, so a student with no Python can reach MLIP calculations on a
laptop and then join EW2GC WP4.

**Architecture:** Project-agnostic modules under `modules/`, each a folder with a
`README.md` and at most one notebook that reads inputs from `structures/` and writes to
its own ignored `work/`. Project material under `projects/<name>/`. Student profiles
under `paths/`. A notebook linter in `scripts/` is the test harness: every notebook
must pass the linter and execute headless in the verification venv.

**Tech Stack:** Python 3.11 venv, `mliprun` (editable install from GitHub,
`[neb]` extra for asetools), `mace-torch` (MACE-MP-0 medium, CPU), ASE ≥ 3.23,
pymatgen, `mp-api`, JupyterLab, `nbformat`, `nbconvert`, pytest for the linter.

**Spec:** `docs/design/2026-09-17-onboarding-repo-design.md`

## Global Constraints

- Every mliprun command and every `setup_calculator` call names the model explicitly:
  `--mlip mace` / `mlip="mace"`. The string `--mlip auto` never appears.
- Each calculation notebook (modules 06 to 10, capstone) opens with the section
  `### Before you run this for a project` listing its canon IDs (table in the spec).
- Each notebook executes on CPU in under 10 minutes in the verification venv.
- Notebooks follow `~/.claude/skills/notebook-style/SKILL.md` (heading plus nested
  bullets; printed output as label line then bare value, unit in the label) and figures
  follow `~/.claude/skills/plot-style/SKILL.md`. Read both before writing a cell.
- Plain international English: short sentences, common words, define every term at
  first use, no idioms. The reader is a materials scientist, not a programmer.
- Windows, macOS and Linux are all addressed in module 00; only macOS is executed.
- Module 11 is written for a person at a terminal. It contains no agent mechanics: no
  SSH connection sharing recipes, no "ask the assistant", no dispatch agents.
- `projects/ew2gc/DECISIONS.md` copies only what `~/computers/EWaste2GreenCat/CANON.md`
  records (C1, C5, E-p1 as of 2026-07-25). Every other master canon ID is "not
  recorded, ask Juan before running".
- The verification venv is `~/venv/onboarding-mace`, built by following
  `modules/00-setup/README.md` literally (paths substituted). Kernel name in every
  notebook is `python3`.
- Git: commit after each task with a `feat:`/`docs:`/`test:` message ending with the
  attribution line `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. Never
  commit `work/`, `.traj`, model weights, or `.ipynb_checkpoints`.

### Notebook builder template

Each notebook is generated by a builder script kept in the session scratchpad (not
committed), then executed in place. Template:

```python
# $SCRATCH/build_<module>.py
from pathlib import Path
import nbformat
from nbformat.v4 import new_notebook, new_markdown_cell, new_code_cell

OUT = Path("~/github/work/student-onboarding/modules/<NN-name>/<name>.ipynb").expanduser()
cells = []

def md(s):
    cells.append(new_markdown_cell(s.strip("\n")))

def code(s):
    cells.append(new_code_cell(s.strip("\n")))

md("""
# <Title>

- <one clause: what this notebook does>
- <one clause: what you need before starting>
- <one clause: what you will be able to do after>
""")

code("""
from pathlib import Path
WORK = Path("work")
WORK.mkdir(exist_ok=True)
STRUCTURES = Path("../../structures")
""")

# ... sections ...

nb = new_notebook(
    cells=cells,
    metadata={
        "kernelspec": {"name": "python3", "display_name": "Python 3", "language": "python"},
        "language_info": {"name": "python"},
    },
)
nbformat.validate(nb)
nbformat.write(nb, OUT)
print("wrote", OUT)
```

- [ ] **Step 3: Write the linter**

```python
#!/usr/bin/env python3
"""Check an onboarding notebook against the house rules. Exit 1 on any failure."""
import re, sys
from pathlib import Path
import nbformat

CANON_DIRS = ("modules/06-", "modules/07-", "modules/08-", "modules/09-", "modules/10-", "capstone")
AUTO = ("--mlip auto", 'mlip="auto"', "mlip='auto'")
LABEL_VALUE = re.compile(r"""print\(f?["'][^"'\n]*:\s*\{""")
LINE_OK = re.compile(r"^(#|-|\*|\d+\.|\||>|<|    )")

def check(path: Path) -> list[str]:
    fails = []
    nb = nbformat.read(path, as_version=4)
    try:
        nbformat.validate(nb)
    except nbformat.ValidationError as e:
        fails.append(f"nbformat: {e}")
    if nb.metadata.get("kernelspec", {}).get("name") != "python3":
        fails.append("kernelspec: name must be python3")
    cells = nb.cells
    if not cells or cells[0].cell_type != "markdown" or not cells[0].source.startswith("# "):
        fails.append("first cell: must be a markdown title starting with '# '")
    for i, c in enumerate(cells):
        src = c.source
        if any(a in src for a in AUTO):
            fails.append(f"cell {i}: '--mlip auto' is banned, name the model")
        if c.cell_type == "markdown" and "$$" in src:
            fails.append(f"cell {i}: display math $$ is banned, use backticks")
        if c.cell_type == "code" and LABEL_VALUE.search(src):
            fails.append(f"cell {i}: label and value printed on one line, split them")
        if c.cell_type == "markdown":
            fenced = False
            for ln in src.splitlines():
                if ln.strip().startswith("```"):
                    fenced = not fenced
                    continue
                if fenced or not ln.strip():
                    continue
                if not LINE_OK.match(ln):
                    fails.append(f"cell {i}: prose line must be a heading or bullet: {ln[:60]!r}")
                    break
    p = str(path)
    if any(k in p for k in CANON_DIRS):
        if not any(c.cell_type == "markdown" and "### Before you run this for a project" in c.source for c in cells):
            fails.append("canon: missing '### Before you run this for a project' section")
    mds = [c for c in cells if c.cell_type == "markdown"]
    if not mds or "## Check yourself" not in mds[-1].source or "<details>" not in mds[-1].source:
        fails.append("ending: last markdown cell must be '## Check yourself' with a <details> answer block")
    return fails

def main(argv):
    bad = 0
    for arg in argv:
        fails = check(Path(arg))
        for f in fails:
            print(f"{arg}: {f}")
        bad += bool(fails)
    print(f"{len(argv) - bad} of {len(argv)} notebooks pass")
    return 1 if bad else 0

if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
```

```python
"""Small builders used by the onboarding notebooks from module 05 onward.

They package what modules 02, 04 and 05 teach by hand, so later notebooks start from a
known structure in one line. Teaching values throughout: three layers, one frozen,
10 Å vacuum. A project decides its own (canon S2, S5, S8).
"""
from ase import Atoms
from ase.build import fcc111, add_adsorbate, molecule
from ase.constraints import FixAtoms

A_PT = 3.92   # Å, ASE's reference lattice constant for fcc Pt

def pt111_slab(size=(3, 3, 3), vacuum=10.0, fix_bottom_layers=1) -> Atoms:
    slab = fcc111("Pt", size=size, a=A_PT, vacuum=vacuum)
    tags = slab.get_tags()                     # 1 = top layer, increasing downward
    n_layers = size[2]
    fixed = [i for i, t in enumerate(tags) if t > n_layers - fix_bottom_layers]
    slab.set_constraint(FixAtoms(indices=fixed))
    slab.pbc = (True, True, False)
    return slab

_ADS = {
    "O":   (Atoms("O"), 0),
    "OH":  (Atoms("OH", positions=[[0, 0, 0], [0, 0, 0.97]]), 0),
    "OOH": (Atoms("OOH", positions=[[0, 0, 0], [0.9, 0, 1.1], [1.7, 0, 0.8]]), 0),
}
_HEIGHT = {"O": 1.3, "OH": 1.9, "OOH": 2.0}

def pt111_with_adsorbate(species: str, site: str, size=(3, 3, 3), vacuum=10.0, height=None) -> Atoms:
    slab = pt111_slab(size=size, vacuum=vacuum)
    ads, anchor = _ADS[species]
    h = _HEIGHT[species] if height is None else height
    add_adsorbate(slab, ads, height=h, position=site, mol_index=anchor)
    return slab

def molecule_in_box(name: str, box=12.0) -> Atoms:
    m = molecule(name)
    m.set_cell([box, box, box])
    m.center()
    m.pbc = True
    return m
```
